General Info

  • This function shows all bets which have Mix Parlay and System Parlay bet types and the details of each single bet.
  • Mix Parlay/System Parlay tabs: switch between Mix Parlay and System Parlay bet lists.
  • Mix Parlay means bets in a combination of two or more selections placed as one wager. If all selections should win then the Parlay wins and will be paid at the combined odds of the two or more selections. If one (or more) selection should fail to win then the Parlay loses. If one (or more) selections should be postponed then the odds for that selection will revert to 1.00 odds.
  • System Parlay or Combination Mix Parlay is similar to Mix Parlay bet as it is a bet type that allows the punter to pick at least 3 teams and bets them as a Parlay. When placing bets on Mix Parlay, members are allowed to choose whether they want to play System Parlay. When members tick on System Parlay, the total stake will be multiplied. Note that, a System Parlay bet which combines different selections within the same event or match is not allowed, whereby the outcome of one affects the other.

Search Filters

  • Currency: filters tickets placed in selected currency.
    • All: tickets of all supported currencies will be listed out.
  • Based EUR/USD: All figures will be converted to EUR/USD for reference only. The based currency list contains EUR, USD and a dynamic option. The dynamic option will vary when a specific currency is selected in Currency field (except EUR and USD currency).

Report Guidelines

  • External ID: the username registered by ticket owner.
  • System ID: the numeric sequential ID generated from system for each account.
  • Trans.Time: a unique reference number given to each bet ticket in the system including a timestamp of the time and date that the ticket was accepted.
  • Choice: click Mix Parlay/System Parlay to show details of sub-tickets such as customer choice, bet type, betting product, match and league.
    • Details (in System Parlay): displays results of settled bets.
  • Odds: multiply the single bet odds together.
  • Stake: sum of all stakes of each outcome.
  • Status: display status of ticket.
