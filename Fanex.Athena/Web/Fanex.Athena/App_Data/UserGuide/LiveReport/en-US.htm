General Info

  • The report displays the win loss amount for different betting products within a selected date range.
  • Data are available from last 3 months up to the current date. For more historical data available since January 2010, you can click View history report.
  • This report contains only won/lose/draw tickets of Live matches.

Search Filters

  • Currency: selects the currency which data will be retrieved.
    • All: all supported currencies will be listed out.
    • Based EUR/USD: All data will be converted to EUR/USD for reference only. The based currency list contains EUR, USD and a dynamic option. The dynamic option will vary when a specific currency is selected in Currency field (except EUR and USD currency).

Report Guidelines

  • Product: the list of products having data within the selected date range. For more detail win loss, click on each product type.
    Note that detail data drilling down from product types are only available from last 14days up to the current date.
  • Customer W/L: customer net win loss for each product.
  • Turnover: total Customer turnover.
  • Bet Count: total bet tickets of selected products.
  • Licensee W/L: the win loss amount Licensee has settled with Customer.
    Licensee Win/Loss = – (Customer Win/Loss)
  • Comm: Total Licensee commission received from each Product.
  • Amount Due To: the settlement amount that Licensee has paid or received for each Product.
    Note that: for Amount Due To, the black negative number indicates the Licensee receiving amount and black positive number indicates the Licensee paying amount
    • For (Sportsbook, Number Game, Live Casino, Virtual Sports) products,” Amount Due To” is the settlement amount between Licensee and Company.
    • For Racing product,” Amount Due To” is the settlement amount between Licensee and Racing Partner.
    • For BA, “Amount Due To” is the settlement amount between Licensee and BA service.
