一般信息

  • 本功能提供赛事单双盘, 1X2, 和局/不是和局(DND)的投注预测。

搜索过滤器

  • 货币：以货币来进行筛选。
    • 全部：列出所有支持的货币。
  • 基于欧元/美元：所有数据将转换为欧元/美元，仅供参考之用。基于货币列表包括欧元、美元和一个动态货币选项。动态货币选项会因货币栏内选择的特定货币而不同（除了欧元和美元以外）。

报告指南

  • 单双盘: 表示有更多的投注在"单"或"双"。
    单双盘总投注 = 总单盤 - 总双盤。
    • 正数 表示更多”单”的交易额。
    • 负数 表示更多”双”的交易额。
  • 1X2: 下注在一场赛事三种可能结果中的任何一种(输、赢、和局)。
    总投注 1X2 = 每张票赌注的加总。
    • 1 代表首先被提及的队伍（通常是主队）。
      主队预测 =（主队投注额 * 主队赔率）–（和局投注额 + 客队投注额）。
    • X 代表赛事结果平手。
      和局预测 =（和局投注额 * 和局赔率）– （主队投注额 + 客队投注额）。
    • 2 代表第二个被提及的队伍（通常是客队）。
      客队预测 =（客队投注额 * 客队赔率）–（和局投注额 + 主队投注额）。
  • : 显示选定比赛的所有投注。
