General Info

  • The report contains only won/lose/draw tickets.
    Notes that tickets of Mix Parlay, System Parlay, Outright are not included in this report.
  • Data can be retrieved from maximum last 14 days up to the current date.

Search Filters

  • Currency: selects the currency which data will be retrieved.
    • All: all supported currencies will be listed out.
    • Based EUR/ USD: All data will be converted to EUR/ USD for reference only. The based currency list contains EUR, USD and a dynamic option. The dynamic option will vary when a specific currency is selected in Currency field (except EUR and USD currency).
  • Status: selects the status of bet ticket to be displayed.
  • A red negative number indicates a loss for Licensee whereas the black positive indicates a win.

Report Guidelines

  • External ID: the username registered by ticket owner.
  • System ID: the Numeric sequential ID generated from system for each account.
  • Trans. Time: a unique reference number given to each bet in the system, each attached with a timestamp of the time and date the bet is accepted.
  • Choice: shows detail information of Bet ticket such as bet type, selected team, match name, and league of the match.
  • Odds: displays the fixed odds value of each ticket.
  • Stake: the amount of money that Customer has bet on each ticket.
  • win loss: customer net win loss within a selected date range.
  • Licensee WL/Comm: the win loss amount Licensee has settled with Customer.
  • Status: shows the status of bet ticket.
