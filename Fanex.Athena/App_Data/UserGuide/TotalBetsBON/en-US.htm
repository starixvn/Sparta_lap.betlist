General Info

  • This function lists all tickets which are placed on 'Both/One/Neither team to score' bet type.

Search Filters

  • Currency: filters tickets placed in selected currency.
    • All: tickets of all supported currencies will be listed out.
  • Based EUR/USD: All figures will be converted to EUR/USD for reference only. The based currency list contains EUR, USD and a dynamic option. The dynamic option will vary when a specific currency is selected in Currency field (except EUR and USD currency).

Report Guidelines

  • External ID: the username registered by ticket owner.
  • System ID: the Numeric sequential ID generated from system for each account.
  • Trans.Time: a unique reference number given to each bet ticket in the system including a timestamp of the time and date that the ticket was accepted.
  • Choice: show details of bet ticket such as customer choice, bet type, betting product, match and league.
  • Odds: odds value of ticket.
  • Stake: stake value of ticket.
  • Status: display status of ticket.
