一般信息

  • The report summarizes daily win loss in AG Casino.
  • 此报告提供最新数据。您每次查询可以过滤最多3个月内的数据。
  • 在每天3:30 AM（GMT-4）过后，报告会显示前一天的数据.

搜索过滤器

  • 货币： 以货币來选择所会列出的数据。
    • 全部： 列出所有支持的货币。
    • 基于欧元/美元: 所有数据将转换为欧元/美元，仅供参考之用。基于货币列表包括欧元、美元和一个动态货币选项。动态货币选项会因货币栏内选择的特定货币而不同（除了欧元和美元以外）。
  • 排除测试数据： 排除测试账户中的每张票。

报告指南

  • 交易额: 选定的日期范围内的会员总交易额。
  • 总交易数: 选定产品的投注票总量。
  • 会员输赢
    • 输赢: 会员下票的输赢金额。
    • 佣金: 每张票所计算的总佣金金额。
    • 总和: 总输赢金额含佣金。
      总和 = 总输赢金额 + 佣金
  • 承租公司输赢： 承租公司已与会员结算的输赢金额。
    承租公司输赢= - (会员输赢)
