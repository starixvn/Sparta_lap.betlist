General Info

  • The report contains only won/lose/draw tickets.
  • Data can be retrieved from maximum last 14 days up to the current date.
  • Data can be filtered by Currency.

Search Filters

  • Currency: selects the currency which data will be retrieved.
    • All: all supported currencies will be listed out.
    • Based EUR/USD: All data will be converted to EUR/USD for reference only. The based currency list contains EUR, USD and a dynamic option. The dynamic option will vary when a specific currency is selected in Currency field (except EUR and USD currency).

Report Guidelines

  • Meeting – Currency: league name along with supported currency.
  • Race: race number which supports you to view detail win/loss by clicking on it.
  • Win TO: Member turnover amount for Win betting type.
  • Place TO: Member turnover amount for Place betting type.
  • W/P TO: Member turnover amount for Win Place betting type.
  • Total TO = Win TO + Place TO + W/P TO
  • Dividend Won: sum of member Winning and Stake amounts.
  • Comm: Licensee commission received from Racing Partner.
  • Amount Due to Racing: the settlement amount between Licensee and Racing partner.
    Amount Due to Racing = Total TO – Dividend Won - Comm
    Note that for Amount Due to Racing, the black negative number indicates the receiving amount from Racing partner and black positive number indicates the paying amount to Racing Partner.
