General Info

  • This function lists all tickets which are placed on 'Both/One/Neither team to score' bet type.
  • Home no bet: winning amount if licensee wins the bet tickets that predict the result either win or draw of the match for Away team only. It means you cannot bet on home team in any case.
    • Draw: if the result is draw then bets on this option are winners.
    • Away: if the result is away then bets on these options are winners.
    • REFUND: If the result is home then all bets are refunded.
  • Away no bet: winning amount if licensee wins the bet tickets that predict the result either win or draw of the match for Home team only .It means you cannot bet on away team in any case.
    • Home: if the result is home then bets on these options are winners.
    • Draw: if the result is draw then bets on this option are winners.
    • REFUND: If the result is away then all bets are refunded.
  • Draw No bet: winning amount if licensee wins the bet tickets that predict the team to win the match and if the result after regular time of play or at the end of that scheduled time is a draw, all bets will be refunded.
    • Home: if the result is home then bets on these options are winners.
    • Draw: if the result is away then bets on this option are winners.
    • REFUND: If the result is draw then all bets are refunded.

Search Filters

  • Currency: filters tickets placed in selected currency.
    • All: tickets of all supported currencies will be listed out.
  • Based EUR/USD: All figures will be converted to EUR/USD for reference only. The based currency list contains EUR, USD and a dynamic option. The dynamic option will vary when a specific currency is selected in Currency field (except EUR and USD currency).

Report Guidelines

  • External ID: the username registered by ticket owner.
  • System ID: the Numeric sequential ID generated from system for each account.
  • Trans.Time: a unique reference number given to each bet ticket in the system including a timestamp of the time and date that the ticket was accepted.
  • Choice: show details of bet ticket such as customer choice, bet type, betting product, match and league.
  • Odds: odds value of ticket.
  • Stake: stake value of ticket.
  • Status: display status of ticket.
