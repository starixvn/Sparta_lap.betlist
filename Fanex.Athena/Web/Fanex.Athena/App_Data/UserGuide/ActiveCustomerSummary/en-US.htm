General Info

  • The report summarizes number of active customers in a particular products and time. These customers are grouped by product and month.
  • Active customer is a customer that placed bet in selected time.
  • Data is available since 01/01/2015 up to yesterday. Data range is supported within 3 months.

Search Filters

  • Currency: filters customers who use selected currency.
    • All: displays all customers using offered currencies.
  • Product: selects the Product type which customers placed bets.

Report Guidelines

  • Product: Product type which customers placed bets.
  • Month: number of customers placed bets in each month of selected time.
